## Evidence strength and limits

1. **D-11-A original supplier PDF** is the strongest material-spec source. It contains a technical specification dated 1 Jan 2024, indicative nutritional information dated 1 Jan 2025 and separate allergen pages. Nutrition values are indicative, not batch results. Protein/fibre and sieve method support the matrix/dispersion distinction. No certifications are transferred to ZL.
2. **S8 supplier page** supplies fat, pH and colour. The supplier labels a 7.9–8.3 band “Highly Dutched (>8)”; drafts retain the numerical band without trying to repair that category shorthand.
3. **Acticoa page** was obtained through web_extract; direct HTTP returned 403. Captured SKU text has no numerical flavanol guarantee. We do not import a 7.5%, 8% or 2.5-g-serving claim from a different historical/source context.
4. **FSAI August 2015 opinion** was retrieved as an actual three-page PDF. It describes Mars’ then-proposed extract and comparator; it is not a current supplier TDS, universal safety ceiling, present-day claim permission or manufacturing recommendation. The aqueous-acetone route is a historical described process, not a recommendation to use that solvent in another project.
5. **Miller 2008** abstract was independently recovered through Europe PMC core API after PubMed direct access returned a non-body page. Numerical category means are survey results, not current supplier assays. Full methods were not obtained. Do not mix these assay values with later-method assays as if equivalence were proven.
6. No contemporary stand-alone extract TDS was verified. Historical CocoanOX search results were not promoted into current commercial specifications. This is the main gap if the parent wants a current extract SKU comparison before publication.
7. Some keyless searches failed with 403. A clinical query failed; no clinical outcome claims were drafted. No real-browser recovery was used because the task forbids BrowserMan and sufficient direct evidence was available.
