# ZL主动选题与创作规则（用户2026-09-20最新要求）

本规则扩展现有每日GSC流程，不取代真实性/审查/发布安全要求。

## 最新工作原则：先发散，再聚焦（用户明确纠正）
计划任务只是唤醒与续作机制，不是固定选题清单。五路发现是可选工具，不要求每轮机械覆盖所有来源，也不把候选数量当创新成果。

每轮从一个真实信号或反常现象出发，先提出多种不同解释与内容机会：更换受众、使用场景、价值链环节、时间尺度，寻找反例和跨行业类比。不要预先锁死茶/甜菊/积雪草，也不要只是把同一篇文章拆标题。允许发现过程中改题、合并和放弃，保留简短的理由。

然后聚焦：比较读者价值、真实业务关联、原创证据可得性、与现有内容差异、执行成本，选一个最值得验证的核心问题。先做小验证（关键来源、少量真实商品或反例），再决定文章/工具/图表/实验建议/不做。未经验证的跨领域关系只是假设，不写成事实。既有周产量是容量方向而非配额，不能迫使低价值选题上线。

复盘要回答：发现了什么原先没想到的问题？哪些假设被推翻？为何选择这个角度而非另外两个？验证带来了什么变化？交付了什么？不以固定栏目汇报代替判断。可长期积累不成熟创意，证据与场景成熟时再推进。

## 五路发现
1. BrowserMan真实Google关键词搜索：观察5-10个相关结果（视返回能力），提取结构优势、未回答问题、证据缺失、可整合分散知识、可深挖机制；不要复制竞争文章。记录查询/时间/地区实际可证信息/URL；不能冒充搜索量排名研究。
2. 论文：PubMed/Europe PMC/Crossref及出版商原文，关键词、综述、引用链、负结果与相反证据；区分体外、动物、人体、材料工艺及剂量形态，不把论文变成疗效营销。只读摘要就明确范围；不能把预印本/撤稿当确定证据。
3. 行业社区：BrowserMan目录先查可用search schema，再公开讨论如Reddit/X/知乎/LinkedIn等，研究配方痛点、标签理解、采购疑问、产品反馈；不读取私信/封闭社区，不联系发帖者，不发布评论；帖子热度只是平台样本不是总体需求。
4. 跨行业热点与新闻：运动赛事、办公习惯、饮品消费、零售变化、供应链、气候与政策等。先核新闻日期/原始来源，构建“事件→真实行为/商业变化→配方或供应问题→相关植物材料→实用内容”的证据链；不强蹭悲剧、不暗示名人代言、不从热点推出未经证明健康效用。新闻只是触发器，文章可产出长期有用知识。
5. 自有电商观察与GSC：原创商品样本、规格/剂量口径、已展示词/实际落地页；不等待曝光阈值，无GSC记录也可立题。
