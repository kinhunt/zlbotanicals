修订日期：2026-09-27。范围：研究修复和既有百科插入稿；未修改网站、未发布、未写 backlog。旧稿仅作历史记录，保存在 `ORIGINAL-RESEARCH.md`；旧来源逐字节复制到 `sources/`。本稿替代旧稿的研究结论，不沿用旧稿的“A档=事实正确”判断。来源 ID 沿用原台账，新增表图见来源清单；SHA-256 与逐条主张见 `source-manifest.json`、`claim-evidence.json`。

## 1. 原文核验后的核心修正

### C01｜乳化方向已核实，不是术语猜测
S15（PMC4852572）摘要明确写 `oil-in-water emulsion cream`，Methods 再写 `cosmetic emulsion O/W`。S09（US10980851B2）权利要求1明确写 `oil-in-water emulsion`。两者都是**水包油 O/W**：油为分散相、水为连续相。**油包水是 W/O**。旧稿中两项材料所有“油包水”表述均撤回。凝胶是独立载体，不称为 O/W 乳液。

### C02｜保湿试验没有报告第四个标志物的含量
S15 Methods 的实际材料句为：`Dried extract of Centella asiatica (Herbalia® Centella) containing 10% active constituents (madecassic acid, asiatic acid, asiaticoside)`。这是三种成分合计的标称活性含量，不是各10%。madecassoside（羟基积雪草苷）只在植物背景讨论中被提及，不能据此写入试验材料的10%活性成分清单。正确单元格是“**试验材料未单独报告，不代表检测为零**”。

已下载并目视核对原始 Table 1、Table 2 图片，而非只看 JATS 的表标题：两表只有 `Centella asiatica extract` 原料行，没有任一单体含量。它们不能补足第四标志物。原 JATS 的表本体为 graphic，不含结构化单元格。

### C03｜原论文还有配方身份冲突，必须保留
- 摘要及试验正文：2.5% 和5%（w/w）提取物；25名18–55岁健康志愿者，前臂，每日两次，4周；新鲜配方 pH 5.5。
- **Table 1和Table 2的提取物行都印为3%**，不是2.5%或5%。乳液表列水79.75%，按印刷数字合计100%；凝胶表首行显示10，提取物3、水96，另有TEA q.s.。不要自动将首行改成1.0，也不要替作者调整水量。
- Methods 先写购入商品干提取物，随后写 dried Centella 以70%（v/v）乙醇、10:1（体积/质量）溶剂原料比、25°C、24小时处理。文字没有清楚交代商品粉末、该提取步骤与最终添加物干物质之间的关系。
- 因此可报告“正文描述的试验浓度及其结果”，但不能把论文重建成已验证生产配方，也不能用10%×5%推算真实成品三萜含量。未找到作者澄清；这不是证明论文无效，而是具体可复现性限制。

## 2. 可保留的 preparation → outcome 证据

### C04｜外用保湿：有结果，也有明确材料约束
S15 Results报告4周后，5%乳液和5%凝胶的角质层含水量分别增加25%、22%；TEWL分别下降18%、15%，空白基质的TEWL下降5%，原文以control area作比较并报告P<0.05。不要把18%说成“比安慰剂多下降18%”，也不将二者相减当作经检验的处理效应。这里是健康前臂上的特定配方结果，不是所有积雪草原料的通用效力或推荐添加量。

对公开插入稿采用方向性结果：作者报告正文所述5%配方在所测条件下保湿表现最好，同时保留一次配方表3%不一致的说明。这样能补足现有 effects 主要讲传统药用与口服认知、却缺少具体外用人体试验的空缺，且不放大未经独立重算的百分比。

微炎症部分是烟酸甲酯诱发模型，不能直接换成湿疹治疗、术后伤口修复或长期抗衰老结论。固定左右前臂分配载体；不将本文称为随机双盲临床试验。

### C05｜提取比较：表2确有四标志物，但不是保湿材料的检测报告
S10（PMC11490722）Table 2，单位原样保留 mg/g：

| 标志物 | 甲醇 | 水 |
|---|---:|---:|
| Madecassoside | 8.21 ± 0.12 a | 7.74 ± 0.15 b |
| Asiaticoside | 7.82 ± 0.11 a | 7.59 ± 0.21 a |
| Madecassic acid | 4.44 ± 0.14 a | 2.48 ± 0.11 b |
| Asiatic acid | 3.38 ± 0.11 a | 1.66 ± 0.06 b |

旧稿“同一成分在不同溶剂间差异具统计学意义”的全称表述撤回：甲醇和水的asiaticoside共享字母a，不能说五溶剂任意两组均显著不同。表脚注写“in a column”，与表格按成分跨溶剂排布的阅读方式不完全协调；不擅自改脚注，不据字母重建统计模型。保留最窄结论：不能从该表宣称所有组间差异显著。

该研究测定提取物组成及体外化学抗氧化指标；不是人体皮肤功效试验。原 mg/g 不改写成纯度百分比或干叶回收率。既有 insights 已有该研究，不再重复一整段五溶剂工艺。

### C06｜EMA：40/60是所述精制材料的身份，不是植物统一组成
S11官方2022评估报告区分药材与极端纯化、再组合的TECA类材料：报告描述40% asiaticoside与60% asiatic/madecassic acids；同时说明TTF的两酸内部比例未清楚定义。不能把29–30%每种酸或某一商品窗口当作所有TECA/TTF材料的固定实测值。药材最低6%为“total triterpenoid derivatives, expressed as asiaticoside”，不应收窄翻译为“总三萜苷”。这些是该版评估所引用的定义，不是2026年所有药典、供应商或市场的现行规格认证。

旧稿药用剂量、跨市场法规、ECa233摘要和普遍性药代判断不进入插入稿。没有本品材料与临床桥接，不据此生成口服剂量或临床利益。

## 3. 专利数字重新核对：权利要求、说明书和分母分开

### C07｜US8486900B2（S08全文；S04为旧权利要求摘录）
- Claim 1：madecassoside + terminoloside + asiaticoside **合计≥75 wt% / 最终提取物总重**。
- Claim 1(g)：用于标准化回配的第二提取物，madecassoside + terminoloside **合计>95 wt% / 第二提取物总重**。严格大于，不是≥95%，也不是每种成分95%。
- Claim 5：asiaticoside : (madecassoside + terminoloside)质量比 **5:95至25:75**；说明书用括号明确二元合计。不是asiaticoside占完整提取物必然5–25%。
- Claim 6：madecassoside : terminoloside **30:70至70:30**；Claim 7（从属于6）收窄至 **40:60至60:40**。后两条是二元内部质量比，不是完整提取物的纯度。
- Claim 1还包含工艺步骤和施用方法，不能缩成“≥75%即落入专利”或把阈值当成有效添加量。本文不判断侵权、有效性或当前法律状态。

### C08｜US10980851B2（S09全文；S05旧摘录）
Claim 1要求：

| 项目 | 约数范围及口径 |
|---|---|
| Centella提取物 | about 0.0001%–1.5%，总配方重量口径 |
| 其中asiaticoside | about 20%–60%，**提取物重量**口径 |
| 其中两酸合计 | about 40%–80%，**提取物重量**口径；不是每种酸各40%–80% |
| Avena提取物 | about 0.0001%–10% |
| Ceramide | about 0.001%–1% |
| Lipid bilayer structurant | about 0.1%–15%，总配方重量 |
| 防腐剂 | at least about 0.01%，总配方重量 |
| 皮肤可接受载体 | about 50%–98%；本条明确O/W水包油 |

说明书definitions进一步规定：百分比默认占总配方重量；组分水平默认指active portion、排除所举残留溶剂等杂质。不能不加区分地把商品溶液投料百分比视为专利活性口径。20–60与40–80是窗口，不是任意上限可同时相加的配方，不推出普遍40:60精确比例。Claim 6另列一项独立组合物，**没有重复Claim 1的O/W限定**，不把Claim 1措辞强加到全部权利要求。

CAST在说明书/表注的36–44% asiaticoside和56–64% genins是该专利记载的商品材料窗口，不等于Claim 1范围，也不是当前供应商批次证书。

### C09｜额外查出的旧稿误判：专利并非只有细胞实验
S09 Table 8是角质形成细胞基因表达相似性矩阵，CAST 0.001 wt%与TECA 0.01 wt%的测试浓度不同，不能把相似度当成同剂量功效排名。表下注“Madecassoside”材料的HPLC规格实为madecassoside与terminoloside合计≥95%，不可称为纯madecassoside单体对照。

但旧稿“专利比较数据仅体外／不提供人体结局”的全称断言不成立：**Example 4、Tables 5–7确有7天消费者使用问卷**，五组人数为11、12、14、14、14，分属两项测试；包括症状自评、接受度及负面皮肤感受。Table 6星号采用80%或90%置信水平，不是通常读者可能默认的95%。正确说法是：专利同时披露细胞实验和短期消费者自评，授权本身不是独立临床验证；不将这些数据改写成治疗证明，也不隐瞒其存在。
