# 英国奶茶与植物基饮品仍适用现行糖税豁免，扩围拟于2028年实施

*现行规则与已公布方案核对至2026年9月20日。本文解释产品适用范围与配方证据准备，不提供个别企业的纳税结论。*

预包装奶茶含有牛奶，并不意味着一定豁免英国软饮料行业税（Soft Drinks Industry Levy，SDIL）。按照HMRC现行指南，乳饮豁免要求每100ml调制后的饮品至少含75ml符合定义的乳；植物乳替代饮料则有另一组条件。[4] 英国政府计划取消含添加糖乳饮及乳替代饮料的相应豁免，并将起征糖含量门槛从每100ml的5g降至4.5g，拟适用于2028年1月1日起发生的应税事件。[1][7]

现行规则和未来方案必须分开看。HMRC于2026年7月发布的材料仍属于草案及配套说明，并表示最终指引将另行公布，不能据此把扩围写成已经实施。[2][8] 对茶饮品牌、进口商和研发团队而言，首先需要弄清的是成品配方和供应形态，而不是先用更换甜味剂来推算税款节省。

## 现行规则与2028年计划，差别在哪里？

下表用于比较产品范围，不是税额计算表，也不涵盖企业注册义务的全部判断。

| 判断事项 | 2026年9月核对的现行规则 | 拟适用于2028年1月1日起应税事件的方案 |
|---|---|---|
| 糖含量门槛 | 对其他条件也符合的饮品，低档为每100ml总糖≥5g且<8g，高档为≥8g。[4] | 下限拟降至4.5g，高档门槛仍为8g；乳饮判断门槛时拟扣除符合资格的乳糖。[2][7] |
| 乳饮豁免 | 每100ml调制后的饮品至少含75ml符合定义的乳，才符合这一乳饮豁免条件。[4] | 拟取消含添加糖乳饮的豁免，改为在糖含量判断中适用乳糖扣除额。[1][2] |
| 植物基饮品豁免 | 符合乳替代饮料条件才可适用该项豁免，并非所有植物来源饮品均可适用。[4] | 含添加糖的乳替代饮料拟纳入；仅由单一核心植物原料释放糖的情形，公布方案仍保留范围外处理。[2] |
| 门店现配杯饮 | 仅向杯、玻璃杯或外带杯分装饮品，不使经营者成为包装商；机器用应税风味浓缩液另有规则。[4] | 政策称开放杯饮品不受此次变化影响，但这不取消既有浓缩液规则。[1][4] |
| 税率年份 | 2026年4月1日起，低档为每10升£2.08，高档为每10升£2.78。[4][6] | 不能将2026年税率直接当作2028年确定税率；HMRC说明各档税率在预算中公布，并于随后4月生效。[2] |

政策宣布、草案发布和规则生效，是三个不同阶段。2025年11月的咨询答复已把原拟2027年4月1日的实施日期推迟至2028年1月1日。[5] 2026年7月的税务影响说明表示，相关立法将纳入Finance Bill 2026–27；详细政策文件则预期在Finance Act 2027中完成立法。[1][2] 草案的适用日期以**应税事件（chargeable event）**为准，不能简化为配方批准日或生产日。[7]

## 现行奶茶判断：乳比例重要，但不是唯一条件

HMRC的一般适用条件涉及生产时添加糖或符合定义的含糖原料、即饮或稀释后每100ml至少5g糖、规定的饮用或调制形式、包装，以及不超过1.2%的酒精体积分数；还需考虑适用豁免。[4] 因此，达到某个糖含量，并不单独决定所有甜饮都要纳税。

在乳饮豁免中，HMRC将动物乳、复原或重组乳、发酵乳、酪乳及规定的乳清形态纳入乳的定义，但不包括奶油。[4] 配方记录应区分符合定义的乳、奶油、植脂末或奶精，以及乳来源原料的总添加量。“含乳制品”不能代替这一区分。

低于每100ml含75ml乳条件的预包装茶饮，现在就可能需要按一般规则评估，不能以为所有奶茶都要等到2028年才与SDIL有关。[4] 反过来，符合现行乳饮条件的产品，也不应提前套用未来取消豁免的方案。这里讨论的是产品范围；企业是否需要注册以及是否有其他可用减免，仍须分别判断。

### “植物基”不等于“乳替代饮料”

现行乳替代饮料条件包括：每100ml至少含120mg钙、源自植物、具有乳的全部或大部分用途、稠度与乳相近，并且不含气。[4] 配方用了燕麦原料，并不能证明成品茶饮满足上述全部条件；果汁或植物提取物饮料，也不会仅因“植物基”这一名称就成为乳替代饮料。

研发资料中，应将原料的商品名称与成品拟采用的税务分类分开。钙含量依据、成品用途、稠度和是否含气，应有对应记录，而不是由营销类别代替判断。

## 2028年拟设乳糖扣除：关键在来源与加工过程

公布方案拟对相关乳饮采用“总糖扣除符合资格的乳糖”后判断门槛，液态乳及奶粉等乳制品中的乳糖可纳入考虑。[2] 2025年咨询答复还明确，乳糖扣除额不以饮品的乳含量百分比为前提。[5] 因此，现行75%乳饮豁免条件，不应被带入未来记录表，变成享有乳糖扣除的最低乳比例。

但并非所有与乳原料有关的糖都可扣除。政策说明排除了单独作为原料添加的乳糖或半乳糖，以及已水解的乳糖；草案也涉及因添加乳糖酶而已经或将要转化的乳糖。[2][7] 原料名称标有“无乳糖”，不能证明其中所有源自乳的糖都可从门槛判断中扣除。

**含乳清的配方需保留人工复核。** 政策说明笼统表示乳清粉中的乳糖不纳入扣除，但草案第4C条又对乳清成分是否在饮品中重组、乳清是否在饮品中复原作了限定。[2][7] 两处文字尚不足以支持一条适用于所有含乳清奶茶的结论。本文不判定具体复原乳清配方的扣除资格；这一点应等待最终指引，或向HMRC、具备英国税务资质的专业顾问核实。

HMRC拟采用的证据框架包括配方用量、供应商出具的典型乳糖含量规格、制造过程、成品营养声明，以及已有检测结果和方法解释。[2] 文件同时指出，目前不能通过实验室分析直接识别产品的游离糖含量。[2] 营养表上的总糖数值有参考价值，却不能独自证明哪些乳糖符合扣除条件。

## 植物基方案看糖的来源，不能只看有没有额外加蔗糖

对于植物乳替代饮料，公布政策拟将仅由单一核心植物原料——例如燕麦或大豆——贡献糖的饮品保留在征税范围外。[2] 如果两种或更多植物原料贡献糖，则需按总糖含量判断；米饮中额外加入米糖浆就是文件列举的例子，即使两种原料都源于稻米，糖浆仍被视为添加糖原料。[2]

这并不意味着“多一种植物成分就一定纳税”。同一政策允许单一核心植物原料贡献糖的乳替代饮料与果汁或蔬菜汁混合后仍处于范围外；但若把植物乳替代饮料中的糖加入纯动物乳，这部分糖会被视为添加糖，再考虑乳糖扣除额。[2] 这些例外必须与一般表述一起阅读，不能只数配料表里出现了几种植物名称。

以燕麦奶茶为例，实际需要查清的是各项原料贡献了什么。配方资料应能分别识别燕麦基底、茶原料、糖浆、香味原料及可能使用的载体。复配原料的组成或糖贡献不明时，应记录缺口，而不是用“无额外蔗糖”替代SDIL判断。下表为假设情景，不是实测商品，也不提供纳税裁定。

| 假设产品或供应形态 | 应如何区分判断 |
|---|---|
| 符合现行乳含量条件的预包装奶茶 | 分开评估当前乳饮豁免与未来拟取消豁免、采用乳糖扣除的方案。[4][2] |
| 低于该乳含量条件的预包装奶茶 | 现在就检查一般适用范围，不假定2028年才首次可能涉及SDIL。[4] |
| 只有单一核心燕麦原料贡献糖的乳替代饮料 | 核对拟设单一原料排除条件，以及成品本身的分类。[2][7] |
| 米乳替代饮料另加米糖浆 | 政策将米糖浆视为添加糖原料，随后需看总糖含量。[2] |
| 含糖植物乳组合加入动物乳 | 按公布的混合饮品区别处理，并核查乳糖证据；不能按原料名称叠加豁免。[2] |
| 使用供应商机器浓缩液制作的门店杯饮 | 区分零售端分装活动与浓缩液本身的供应及适用范围。[4] |

## 干粉、机器浓缩液和饮用酸奶各有边界

HMRC现行指南将以粉末形式销售的饮品列为排除项，而用于饮料分配机的应税包装风味浓缩液，自2023年4月1日起已有相应规则。[4] 干态茶原料、瓶装茶饮和机器用风味浓缩液，不能共用一个未经核查的分类。浓缩液规则看其在机器中的使用方式及调制后的饮品，而不是规格书中是否出现“浓缩”二字。[4]

2028年草案还列出特定的饮用酸奶排除条件：每100ml调制后的饮品至少含90ml发酵乳，且不得为了提高可饮用性而加入其他液体。[7] 奶茶里加了酸奶，不足以证明符合该条件。接近这条边界的产品，应以真实配方和加工过程对照最终文本。

## 改配方之前，先建立一份有版本号的成品资料

眼下最有用的准备，是让供应状态、饮用状态和配方组成可以追溯。HMRC拟提出的乳糖证据类别可作为整理依据；下方工作表是编辑制作的空白模板，不是官方申报表。[2]

建议每个SKU、每个配方版本单独建档，将现行判断与2028年计划分栏记录。附件应覆盖完整配方、原料规格版本、带单位的糖与乳糖资料、相关加工步骤、调制后成品口径及待解决问题。缺失值应明确写为未知，不把空白当作零，也不把暂定意见当成已签署分类。

候选甜味原料可以进入研发记录，但不必成为政策的预设答案。HMRC现行指南不将甜菊列为SDIL定义中的糖，不过这不等于成品配方获得批准，也不证明具体使用合法或销量将增长。[4] 税务范围、原料使用合规和配方表现应分别判断；本文不预测甜菊需求。

询购茶或甜味原料时，可以附上英国市场的目标成品形态及所需成分文件，让供应商围绕实际材料提供资料，而不是要求原料供应商为客户的整款饮品出具税务结论。

## 商业决策前，还需重新确认什么？

本次读取的官方页面仍把扩围放在草案推进阶段，并表示最终指引将后续公布。[2][8] 本次核验没有确认到咨询后的已成法扩围文本，也未解决乳清措辞差异，不构成穷尽议会记录的法律状态意见。依赖2028年分类作商业决定前，应重新核对已通过条文、生效安排、最终HMRC指引和具体产品证据。

实际结论是：**现有SKU按现行规则评估，2028年变化另建证据档案。** 真正影响判断的是成品能否满足豁免条件、糖的来源与处理方式，以及包装和供应形态，而不是“奶茶”或“植物基”这样的营销名称。
