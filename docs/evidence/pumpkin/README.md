# Pumpkin source binding

Corrected drafts and review are byte-exact in `review/`. All 99 original files named by its original-byte manifest are preserved in `originals/`, including all 18 exact-ASIN gallery JPEGs. `source-binding.json` maps each copy to its historical path and hash. No package artwork is reproduced in public pages. Reviewer checker uses historical absolute paths; author replay log is in the release handoff directory.

`editorial-delta.json` permits only one scope paragraph replacement per language, removing collection-workflow narration. Tables remain in their original row/column orientation; all original cells and prose apart from that exact delta are enforced by `tests/pumpkin-protein.test.mjs`. Added captions, chapter navigation, local citations and related reading are presentation additions. No purity ranking.
