# 姜风味热处理 — HOLD / 值得后续取得全文

问题：烘烤如何改变真实气味，而不只改变姜辣素/姜烯酚总量？这比又一篇标志物含量清单更值得做。

综述全文 [1] 仅用于追溯文献，找到Schaller与Schieberle两篇2020年JAFC原始研究，DOI 10.1021/acs.jafc.0c06733和10.1021/acs.jafc.0c06731。前者原始摘要已经通过Europe PMC检索到 [2]，报告稳定同位素稀释定量、香气重组及烘烤后新增香气贡献，提供比仅GC峰面积更强的感官切入点。[2]

但是ACS两个全文入口403，Wayback available无存档。Crossref只提供ACS PDF入口，未取得正文。没有读取原始烘烤时间/温度、原料含水量和完整重组方法，因此不能从摘要推断供应商工艺窗口。现阶段不把综述中的处理条件或“有益变化”搬到稿中。

本轮HOLD，不产出伪完整ENZH稿。下一步优先获取两篇原文及补充材料，随后区分原姜、烘烤姜、油/油树脂、饮料中的表现；不要用姜黄研究替代生姜。原始摘要在`primary-abstract.txt`，元数据在`roast-pubmed.raw`，独立ledger [2]附逐字证据。
