## 2. 受众按采购决策组织，不按角色重复成六篇

| 读者 | 到站要完成的任务 / 实际问题 | 页面须交付的答案与证据 |
|---|---|---|
| 原料采购 | 比较供应商：两个含量、价格能否直接比？报价包括什么？ | 形态、最终组成、含量对象/基准/方法、批次与规格版本；同币种/贸易条款/数量的报价拆项；样品与商业批一致性 |
| 研发 / 配方 | 能否放进饮料、冲调粉或胶囊？为什么高含量样品反而不好用？ | 按终端选择形态；载体占重、颜色风味、分散/溶解区别；明确基底、添加量、热处理和储存条件的试样比较表 |
| QA / 法规 | 身份、检验与用途能否通过内部放行？ | TDS 与真实批次 COA 的对应关系、完整组成和方法；按用途确定的污染物项目；目标市场/食品类别材料资格；真实证书持有人、场所、范围、有效期 |
| 品牌 / 产品经理 | 做何种产品，成本和标签有什么取舍？ | 风味/颜色/成分含量目标；载体与过敏原对配料表影响；单位成品配方成本和开发门槛；研究证据不能直接转成产品功效 |
| ODM / 代工研发 | 如何把采购样品接入现有配方和产线？ | 可传递给工厂的原料组成、工艺窗口需求和验收记录；小试→中试→采购确认节点；提供方案概念不等于具备成品代工能力 |
| 分销商 | 能否向下游稳定复售、追溯与交付？ | 规格版本、可转发资料权限、批次追溯、变更通知；包装、剩余有效期、目的地运输与清关文件要求；不得暗示独家权或稳定现货 |

这些是编辑推断的任务模型，不是用户访谈结果。最先满足采购与研发选型，再让 QA 找到放行依据；品牌、ODM 和分销商通过相同规格资料进入各自决策。

## 3. 当前文案的问题与准确替换

公开采购页包含短 Markdown 正文，但后面叠加五维 dossier、重复知识链接、文献卡和空行业事件区。完整页面的阅读负担远大于单看 `turmeric.md`；只改 Markdown 不足以完成采购重写。[2]

### 例一：首屏从免责声明改成采购价值

原文：“目录提供原料身份与选型背景，不是已批准的 SKU 规格或库存证明。下文技术指标为询价核查主题，具体数值与可供文件须确认。”[2]

问题：第一屏先解释网站没有什么，未帮助读者选材料；正文又重复同一边界。

最终替换示例：
> 饮料、冲调粉与胶囊对姜黄原料的要求不同。采购前，先确定需要香辛风味、黄色着色，还是明确的姜黄素类含量，再比较原料形态、载体和检测结果。本页帮助你整理可比规格、安排样品评价，并提交询价所需的信息。
>
> 具体可供形态、规格文件、样品及交付条件以书面确认为准。

CTA：`提交采购需求`、`咨询样品与资料`；保留现有 request-quote 入口，不新增未经证实的“立即下载 COA”。

### 例二：从“确认载体”解释载体为何影响采购

原文：“确认报告基准和载体，不应将总姜黄素类标为纯姜黄素。”[2]

最终替换示例：
> 报告中的含量应说明测的是姜黄素单体，还是多种姜黄素类的合计，并注明按干基还是交付状态计算。含载体粉末还要给出最终混合粉的含量；混合前色素的检测值不能代表整袋原料。载体不仅影响每公斤有效组分的成本，也会占用胶囊装量，并进入终端产品的配料审核。

### 例三：把防御性应用句改成可执行比较

原文：“可先筛选有色或浑浊体系，不承诺澄清饮料效果。比较沉降、光照、染色与热历史；悬浮体系比较标志物保留前须定义取样方法。”[2]

最终替换示例：
> 饮料试样应使用拟上市产品的基底，记录添加量、pH、均质和热处理条件。在相同条件下比较色泽、浊度、油圈和沉降，再跟踪储存后的变化。澄清饮料还需单独设定透明度要求。测含量时采用约定的代表性取样方式，避免只取上清液造成低估。

### 例四：删除采购页里的内部编辑叙述

原文：“这里是文献综述的编辑阅读，不是拟供规格的试验。下方按原料筛选的论文记录保留原始标题及证据边界。”[2]

替换为一个相关链接：
> 需要比较载体加工原理或研究材料？阅读[姜黄原料的配伍方案与技术限制](/zh/plant-extracts/ingredients/turmeric#formulations)。

不要在采购正文再次铺开人体研究、设备综述与专利详情。保留一条必要说明：“文献中的载体或临床结果不能直接作为拟购原料的性能证明。”

Humanizer 简审：初稿式的“参考议题、需确认、不得推断”反复出现，会把采购页写成审查通知。最终示例用具体对象、比较条件和下一步替代；避免“赋能、全方位、优质高效、一站式”及自夸结尾。仍保留与具体风险对应的限制，不将删除免责声明误作删除事实边界。

## 4. 建议完整页面顺序及实质内容

### H1 姜黄提取物采购

首屏使用上述摘要、两类 CTA、一次供货边界。原有丰富产品插画保持，不将其当批次实物或规格证明。快速目录指向下列采购锚点。

### H2 按产品用途选择原料形态 `#material-selection`（拟新增）

用一张“候选材料—采购比较重点—适用试验”表，不伪装可售 SKU：
- 姜黄粉：组织与香辛风味仍在，属于对照选项而非提取物同义词；用于风味型调味或冲饮时评价粗粒、沉淀和风味。
- 油树脂：关注着色组分及挥发油/树脂、形态和组成；调味食品比较油相分布与风味。
- 富集/结晶姜黄素类粉：关注含量对象、方法、粒径及配方装量；高含量不等于可以直接用于澄清饮料。
- 含载体分散粉/分散液：列载体、油、乳化剂及最终含量；比较复水、沉降及基底兼容性。
- 预制复合物：仅作为有明确资料时的采购评估方向，核对组成与加工身份；干混辅料不能自动成为同一种复合物。

形态与上述技术区别沿用现有百科的解释；不要把参考形态扩展成已验证供货范围。[3]

### H2 把含量、组成和检测方法写进同一份规格 `#specifications`（拟新增）

字段表应同时列“资料字段”和“如何比较”：
- 植物身份/根茎部位、产品形态、批号、规格版本；材料身份一致才继续比数值。
- 姜黄素单体与姜黄素类合计、分项结果；HPLC 方法/样品制备/单位/干基或交付基准；不能把不同方法结果机械等同。
- 最终载体、油、乳化剂与其他辅料的名称、比例或规格范围；过敏原来源；保密细节走受控审核，不能只写“专有载体”。
- 水分/必要时固形物、粒度、堆密度/流动性（固体剂型需要时）、在定义条件下的分散表现。
- 提取/纯化溶剂、残留溶剂与按市场用途风险确定的农残、元素、微生物、掺假项目。

不填未经批准的“95%”“食品级”“全水溶”等销售值。JECFA 方法背景在百科解释，不搬来当本商品 COA。

### H2 比较每份配方成本，而不只看每公斤报价 `#cost-comparison`（拟新增）

可直接采用：
> 在材料形态、检测方法和含量基准可比时，单位姜黄素类成本可用“每公斤原料价格 ÷ 交付原料中姜黄素类质量分数”作初筛。例如最终混合粉的含量为百分数时，先除以100再代入。若报告按干基给出，应先换算到实际交付基准。
>
> 配方成本还要计入实际添加量、加工损耗和为达到稳定性所需的其他配料。不同载体的材料即使按姜黄素类计算价格相同，也未必具有相同的颜色、分散或装量表现。

这是数学比较工具，不提供虚构报价或暗示成分含量等于功效。着色用途另比较达到同一成品色泽及稳定性要求的成本。报价须对齐币种、税费、运费、贸易条款、检测费用、订单量和报价有效期。

### H2 样品怎样比较，何时进入中试 `#sample-evaluation`（拟新增）

采购页提供试验记录字段，百科解释机理：
- 饮料/植物拿铁：实际基底、pH、添加量与含量基准、均质/热处理、包装及储存时间；颜色、浊度、油圈、沉降、风味。
- 冲调粉：固定水温和搅拌方式；润湿、结团、杯底沉淀，受潮储存后复测。
- 胶囊/片剂：按最终含载体粉计算装量；流动性、混合均匀度、填充差异，以及适用时的崩解/溶出与压片表现。
- 调味/酱料/烘焙：颜色与香辛目标、油水分布、加工前后颜色、苦味；不是等重量互换四种原料。

每次样品保留批号及规格版本，设验收项、方法和判定责任人；小试通过后由实际生产条件验证。样品量、费用、寄送时间以实际确认记录为准，不编造“免费100g、48小时寄出”。

### H2 供应商准入与批次文件 `#qualification`（拟新增）

按用途排列资料，而不是堆“索取”动词：
1. 选型：现行 TDS、完整组成与工艺概述。
2. 样品评价：样品批号、对应真实 COA、方法/单位/验收限值与实际结果；示例 COA 只能展示格式，不能替代样品报告。
3. 准入：企业/供货关系、追溯与变更程序、过敏原资料、目的地用途依据；需认证时核对证书主体、场所、范围、机构与有效期。
4. 放行：交付批次 COA、标签/包装、与批准样品差异及变更、约定项目的复核记录。

页面只能说明待审核资料类型；没有真实资产时不写“全套证书齐备”或“可下载批次 COA”。

### H2 包装、交付与询价信息 `#inquiry`（拟新增）

用户提交：用途及目的地市场、目标形态与含量要求、排除载体/过敏原、加工条件、样品需求、首单量与预计需求、期望到货地/日期、所需文件；含量尚未确定可提交应用需求，不强迫填编造 SKU。

书面报价应说明：确认的供货来源（自产/合作供应/定制评估如实区分）、包装净重与内包装、MOQ/订单量、可供数量和交期、运输条件、储存要求、保质/复验依据与到货剩余期限、币种和贸易条款。此为应确认字段，不是承诺所有条件均已具备。

结尾示例：
> 提交你的用途、目标市场和试样要求。若已有内部规格，可一并附上；尚未确定含量时，先说明成品形态、颜色或风味目标及加工条件，便于判断下一步需要比较哪些材料与文件。

## 6. 防重复与验收要点

- 一个主意图对应一个页面：采购页负责选型、比较成本、样品、准入和询价；百科负责解释与来源。拿铁采购博客维持狭窄的预调粉应用主题，不再扩成第二个通用姜黄采购首页。[2][3]
- 两页各用自己的 canonical，不互相 canonical、不重定向分类、不新建重复 `/turmeric-procurement` URL。无需对百科做关键词清洗；自然提及采购不等于竞争同一主意图。
- 优先清理完整采购页的重复 dossier、文献卡、无匹配行业事件区与通用分类导航，而不是只把 Markdown 加长。相关科学内容留简短摘要与匹配链接。[2]
- 姜黄单品 H1/title 独立；百科 H1 原样；分类标题仍为植物提取物。姜黄专属菜单文案按用户要求保持“姜黄提取物采购”，分类菜单职责不变。
