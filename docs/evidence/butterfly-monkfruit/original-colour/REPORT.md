## 关键发现

1. 蝶豆花pH研究虽支持相对中性下蓝色较稳，原始方法却是**1%HCl–甲醇提取体系**，不能直接当成水提饮料参数。正文就近限定。
2. 乳清蛋白–蝶豆花水提物研究提供实际糖盐相互作用证据，但测的是荧光/结合参数，未验证高蛋白饮料货架期；升温降低结合、蔗糖未显著提高结合的负结果保留。
3. 氯化钙结果文字说“above375mM”，表3的375mM行已与低浓度组不同，正文保留冲突，不发明精确起效阈值、更不提出补钙用量处方。
4. 螺旋藻蓝候选有真实反例：白藜芦醇结合但未提高Tm；测量通道与空白Tm差异也记录。紫甘薯候选聚焦前处理/褐变而非换一个标签页。
5. 美国2025官方资料采用GPO原始全文，保留水提花瓣身份、具体食品类别和“酸奶中的水果配料”限制；不声称中国/EU准入或完整现行法规尽调。
