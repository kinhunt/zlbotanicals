# 饮料用皂树提取物：先选等级，再选液体或粉末

饮料中的植物原料不一定只负责风味、甜味或活性成分。皂树提取物（Quillaja extract）的皂苷具有乳化和起泡用途，可为含油溶性香料或色素的饮料提供另一条原料选择路径。[1] 询样前，先说清要解决的是油相分散、泡沫表现，还是两者兼顾，而不是只问“有没有皂树粉”。

## Type 1、Type 2不是液体和粉末的区别

JECFA 2005年技术评估记载，Type 1的皂苷含量范围为干基10–30%，Type 2为干基65–90%。[1] Type 2是在Type 1基础上，通过色谱或超滤进一步减少多酚、单宁等非皂苷可溶性固形物的材料。[1] 这些是该评估中的材料描述，不能直接当作今天某款商品制剂的供货指标。

对于油溶性香料乳化项目，如果希望减少非皂苷组分的影响，可把食品用途的Type 2等级纳入询样范围。但也不必仅因Type 1的皂苷比例较低，就把它排除在外；应让供应商提供拟供等级的应用资料。不能仅凭类型名称和皂苷含量确定添加量，也不能据此保证成品透明度或保质期。

| 采购时要区分什么 | 实际差别 | 怎样选择 |
|---|---|---|
| Type 1与Type 2 | 区别在于纯化程度和皂苷含量，不是供货形态。[1] | 先明确乳化或起泡任务，再在实际饮料中比较具体等级。 |
| 液体与喷雾干燥粉末 | 技术评估记载，浓缩物既可以液体形式供货，也可喷雾干燥成粉。[1] | 液体计量工艺可先评估液体；干混工艺可先评估粉末。索取配制说明，不默认两者可以直接替换。 |
| 提取物与标准化制剂 | 食品用途原料可能用乳糖、麦芽糊精或麦芽糖醇等调配，也可能含防腐剂。[1] | 要看完整组成及供货状态下的皂苷含量，而不只看提取物本身的标称百分比。 |

## 植物来源，不等于已经说明所有配料

这份评估同时提到，工艺中可能使用卵白蛋白，粉末中可能加入乳糖载体。[1] 这不代表某款现售产品一定有蛋或乳残留，但足以说明：仅凭“植物来源”，不能判断原料是否满足纯素或过敏原相关要求。应针对具体等级索取配料、加工助剂及相关过敏原文件，再决定产品宣称。

液体原料重点确认固形物含量和防腐剂信息；粉末重点确认载体种类及比例、水分。两种形态都应确认皂苷的检测方法及报告基准。如果供应商只提供干基含量，请其同时说明供货状态下的皂苷含量，再比较投料量和报价。不能把总固形物当作皂苷含量。

## 油溶性香料饮料，询样时说清这些条件

说明所用油脂或香料的种类、乳化浓缩液及最终饮料中的油相含量、饮料pH、是否含气、外观目标、可用的均质工艺和目标市场。除了透明度或浊度目标，也要说明可接受的泡沫水平。询样时还应区分：要的是乳化剂原料，还是已经配好的香精乳液。

皂树来源的饮料乳化剂已有商业产品。Ingredion将Q-NATURALE系列用于含增重剂或不含增重剂的饮料乳化体系，其介绍也涵盖透明饮料。[2] 这说明应用路径确实存在，但不代表所有皂树提取物都能获得相同效果。应在目标配方和工艺中比较拟供等级，不能把其他厂商的保质期、粒径或认证直接套用于新原料。

采购前，还要按目标市场确认食品分类、允许用途、使用条件和标签要求。历史技术评估不能替代当前法规核查，也不等于所有饮料都可以使用。可提交应用需求，评估具体项目的原料采购方案；可供等级、文件和适用性需另行确认。
