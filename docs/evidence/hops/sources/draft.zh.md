# 无醇啤酒选酒花原料：补香、调苦与耐光不是同一件事

研究初稿，尚未获得发布批准。须经独立原始资料核查及中英文编辑审阅。

采购需求只写“用于无醇饮料的啤酒花提取物”，还不足以选定原料。产品究竟缺的是酒花香气、苦味，还是需要针对光照异味设计苦味体系？Hopsteiner现有技术资料分别介绍了面向无醇啤酒的分馏酒花油、用于调整苦味的异构化提取物，以及在特定条件下保护啤酒免受光照异味影响的还原苦味酸提取物。[5][7][6]

这些原料不宜按“提取物浓度越高越好”排成一条线。更重要的是先明确所需功能。本文讨论的是资料和试验实际涉及的无醇、低醇**啤酒**。清澈的酒花风味气泡水属于另一种应用，不能仅凭啤酒技术说明书或啤酒试验，就认定其成品表现相同。

## 想补香，先看香气组分与载体

Hopsteiner对Hop oil Type SELECTED FREE的描述是：常规提取后再经蒸馏分馏的酒花油，供货形式为以丙二醇稀释的产品，规格表将苦味物质列为“未检出”。[5] 它与专门提供异α酸的苦味提取物不是同一类采购对象。“未检出”是供应商的规格用语，不能改写为绝对不含；该页面没有给出这一项的检出限。[5]

资料还称，这款油主要含极性酒花组分，专为无醇和低醇啤酒开发。[5] 因此，与笼统的“酒花提取物”名称相比，香气组成和载体更值得优先确认。如果目标是补充酒花香气而不刻意增加苦味，这类原料有进一步评估的理由，但不能据此认定所有香气型提取物都具有相同组成。

供应商建议在冷端使用，通常位于过滤前，并给出添加示例，而非适用于所有产品的固定用量。[5] 讨论替代比例之前，应先说明啤酒基底与添加位置。用丙二醇稀释的酒花油、未稀释油、颗粒酒花和苦味酸水溶液，不能因为都来源于酒花，就按相同质量直接互换。

## 酒精含量降低，对不同香气物质的影响并不一致

Cocuzza等人的中试研究比“没有酒精就带不出酒花香”这一笼统说法更有参考价值。研究人员采用一款经热蒸发脱醇的商业小麦啤酒，调整乙醇含量，再加入Solero品种的Type 90颗粒酒花。投料量为250 g/hl，容器为20升NC桶，酒花直接松散加入，在5°C下半静态接触14天。[3]

干投组分别设为0.5%、3.5%、7.0%和10.5% ABV，每组有三个干投样品；每个酒精水平另设一个不加酒花的对照，并保留一份原始基酒。全部17份试验啤酒均加入Nagardo，以限制微生物污染。[3] 这既不是零酒精水体系试验，也不是商业酒花提取物的对比试验。

香气表中的变化并不整齐：芳樟醇在各干投组之间变化较小；β-月桂烯在最低酒精组明显低于其他组；异丁酸异丁酯从第一组升至第二组后变化不大。香叶醇则没有随酒精含量持续上升，最高酒精组的均值反而低于中间两组。[3]

|---|---:|---:|---:|---:|
| 芳樟醇 | 195.3 | 213.0 | 204.0 | 214.5 |
| 香叶醇 | 193.4 | 246.8 | 250.0 | 198.4 |
| β-月桂烯 | 708 | 13718 | 13974 | 13502 |
| 异丁酸异丁酯 | 166.3 | 238.5 | 238.3 | 237.5 |

以上为论文所列分析结果的组均值，不是感官评分。[3] 原文印刷页码第4页的表格存在两处编辑问题：表下标为“Table 3”，正文却称其为Table 4；表头单位只印到“μG/”，缺少分母。相邻的香气物质正文使用µg/l，为可能的浓度单位提供了语境依据。证据档案保留了不完整表头，没有将其悄悄改正。[3]

作者提出，最高酒精组香叶醇偏低可能与取样误差有关。这只是解释，不能用来替换实测值。作者还将异常高的月桂烯水平与封闭系统、成品基酒中酵母细胞很少联系起来，区别于会去除酵母或冷凝固物的常规生产条件。[3] 因此，不宜把表中差异换算为所有工艺通用的回收率倍数，更不能直接当成香气强度倍数。

这项试验支持的选料原则较为具体：不同酒花组分对酒精含量的依赖程度不同，值得按组成选择香气原料。试验没有使用SELECTED FREE，因此不能把它当作对该商品性能的独立验证。

## 调整苦味，需要另一类原料

供应商将Isomerized Hop Extract 30%描述为异α酸钾盐的水溶液，用于发酵后调整苦味。[7] 这与选择分馏酒花油补香，是两个不同的功能需求。

它的使用说明也解释了为什么“水溶性”三个字不够用。资料警告，不要用啤酒预稀释原液，因为较低pH会导致沉淀；另一方面，又要求在充分混合的位置把原料加入啤酒流中。[7] 两者并不矛盾：配制浓缩预混液，与在大体积流动啤酒中受控加料，是不同操作。也不要把原液稀释条件误当成成品饮料应达到的pH。

无醇项目首先要判断苦味是否不足。如果苦味已经合适，只是酒花香气不够，就不应默认再加一种以增苦为主要目的的原料。具体用量及感官目标仍需在实际基底中评估；现有资料不能给出所有无醇饮料通用的苦味指标。

## 苦味体系耐光，不等于所有风味都稳定

Tetra Iso-Extract被描述为四氢异α酸钾盐的水溶液。供应商明确限定，针对光照异味的保护需要体系完全没有α酸和普通异α酸，还要求避免曾接触这些物质的设备或酵母带入污染。[6]

这属于全流程条件，不是往现有配方里补加一种原料，就能自动获得的保护。它也不意味着所有香气成分、颜色或微生物状态都不会变化。

另一个问题是香气保存。SELECTED FREE资料称其香气组分在啤酒陈放期间保持稳定，但所取回页面没有提供成品啤酒的陈放时长、光照条件或包装对比数据。[5] 应把这项供应商陈述与经过验证的货架期研究分开，不能用它直接回答某款透明瓶无醇产品能否保持预期香气。

## 把采购讨论落到真正需要解决的问题

如果开发的是以酒花香气为主的无醇啤酒，可以先确认供货香气组分、载体、批次组成信息，以及建议的添加位置。若还需要补足苦味，再单独讨论苦味原料。若主要担心光照异味，则应检查整个苦味体系及工艺残留，而不只是最后加入的那一种提取物。

下一轮试验不必照搬论文的颗粒酒花干投方案。更有价值的是在实际基酒和计划工艺中比较候选香气原料，明确是否另行调整了苦味，并将香气特征与苦味分别评价。随后用真实包装和预定储存条件观察成品。以上是建议的开发思路，不是经过验证的生产规程。

这条研究方向的价值在于：**为低醇啤酒选择香气型酒花原料，同时避免把补香、苦味酸投料和有条件的耐光性混为一谈。** 现有证据足以支撑有边界的技术讨论，但不足以支持供应商排名、酒花水配方、货架期保证或健康功效宣称。
