## 产品概述

甜菊（*Stevia rebaudiana*），是菊科多年生草本植物，原产于南美洲。甜菊糖苷是从甜菊叶中提取的天然高倍甜味剂，主要有效成分为甜菊糖苷和甜菊醇糖苷（Rebaudioside A、Stevioside等）。作为一种零热量、零血糖指数的植物基甜味剂，甜菊糖苷正在全球无糖食品饮料市场快速成长。

## 生产工艺

```
甜菊鲜叶 → 干燥 → 超声波提取 → 膜微滤 →
色谱层析分离 → 高效液相层析 → 冷冻干燥 → 成品检测 → 包装
```

### 工艺优势

1. **原料优势**：采用优质甜菊品种，叶片大且甜菊糖苷含量高
2. **提取技术**：超声波提取结合膜分离技术，提取效率高
3. **分离纯化**：高效液相层析（HPLC）精准分离，RebA纯度业界领先
4. **质量控制**：每批次HPLC检测，RebA含量精准可控
