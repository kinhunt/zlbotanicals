## 产品概述

罗汉果甜味剂是从罗汉果中提取的天然高倍甜味剂，主要活性成分为罗汉果苷 V（Mogroside V）。作为一种零热量、零血糖指数的天然甜味剂，它正在全球无糖食品饮料市场快速增长。

## 生产工艺

```
罗汉果鲜果 → 清洗筛选 → 热水提取 → 膜过滤 →
树脂吸附 → 洗脱浓缩 → 喷雾干燥 → 成品检测 → 包装
```

### 工艺优势

1. **原料优势**：采用广西桂林原产地罗汉果，品质稳定
2. **提取技术**：水提工艺，无有机溶剂残留
3. **分离纯化**：大孔树脂吸附技术，高效分离罗汉果苷
4. **质量控制**：每批次 HPLC 检测，含量精准可控
