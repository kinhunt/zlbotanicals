## 配方亮点

### 核心差异化：水溶性姜黄素技术

传统姜黄素最大的问题是**生物利用度极低**（仅1-2%），大部分无法被人体吸收。我们采用**纳米乳化水溶性技术**：

| 指标 | 普通姜黄粉 | 常规姜黄素95% | 振隆水溶性姜黄素 |
|-----|-----------|--------------|-----------------|
| 水溶性 | 不溶 | 不溶 | **完全溶解** |
| 生物利用度 | 1-2% | 1-2% | **提升20-50倍** |
| 冲泡效果 | 悬浮沉淀 | 悬浮沉淀 | **澄清透亮** |
| 口感 | 粗糙土腥 | 苦涩 | **温和顺滑** |

**技术原理**：通过纳米乳化技术将姜黄素包裹在亲水性载体中，形成稳定的水溶性微粒，大幅提升溶解度和吸收率。

### 核心成分1：水溶性姜黄素 — 抗炎抗氧化

姜黄素是姜黄的核心活性成分，具有强大的抗炎和抗氧化功效：

| 指标 | 振隆规格 |
|-----|---------|
| 总姜黄素含量 | ≥10% |
| 水溶性 | 完全溶于水 |
| 稳定性 | 热饮稳定（80°C/30min） |
| 颜色 | 金黄色 |

**作用机制**：姜黄素通过抑制NF-κB通路发挥抗炎作用，同时清除自由基保护细胞。水溶性形式确保有效成分能够被充分吸收。

### 核心成分2：甘草提取物 — 调和增甜

甘草是传统金奶配方的重要组成，不仅提供天然甜味，还能调和口感：

| 指标 | 振隆规格 |
|-----|---------|
| 甘草酸含量 | ≥8% |
| 甜度 | 蔗糖的50倍 |
| 功能 | 护胃、抗炎协同 |

**作用机制**：甘草酸的天然甜味可掩盖姜黄的土腥味，同时甘草多糖对胃黏膜有保护作用，与姜黄形成温和的配伍。

### 核心成分3：生姜提取物 — 温热增效

生姜与姜黄同属姜科，是传统配伍的黄金搭档：

| 指标 | 振隆规格 |
|-----|---------|
| 姜辣素含量 | ≥5% |
| 口感 | 温热微辣 |
| 功能 | 促进循环、增强吸收 |

**作用机制**：姜辣素提供温热感，促进血液循环，同时增强姜黄素的吸收效果。传统阿育吠陀医学中，姜与姜黄常一起使用。

### 协同配伍：黄金三角

```
        姜黄素（抗炎核心）
           /        \
          /          \
    甘草（调和增甜）——生姜（温热增效）
```

三者形成功能与口感的完美平衡：
- 姜黄素提供核心功效
- 甘草调和苦味、增加甜感
- 生姜增添温热感、提升吸收

## 推荐配方

**每包（15g）预调粉配方参考**

| 原料 | 用量/包 | 功能说明 |
|-----|--------|---------|

| 燕麦粉 | 3g | 丝滑口感 |

| 罗汉果苷V（50%） | 50mg | 零卡增甜 |

**冲泡方式**：将一包预调粉倒入200ml热水或热牛奶中，搅拌均匀即可享用。

**产品规格建议**
- 每盒：15包/30包（半月量/月量）
- 每包重量：15g
- 建议零售价：98-168元/盒

### 工艺要点

1. **预混合**：先将水溶性姜黄素与椰子粉充分混合，确保分散均匀
2. **低温干燥**：采用喷雾干燥或冷冻干燥，保护热敏成分活性
3. **密封包装**：铝箔独立包装，防潮防氧化
4. **质量控制**：成品姜黄素含量≥3mg/包，稳定性6个月
