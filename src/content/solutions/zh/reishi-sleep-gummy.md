## 配方亮点

### 核心差异化：无褪黑素配方

市面大多数助眠产品依赖褪黑素（Melatonin），但存在以下问题：

| 问题 | 说明 |
|-----|------|
| 剂量争议 | 市售产品常超过人体自然分泌量10-20倍 |
| 依赖风险 | 长期使用可能抑制自身褪黑素分泌 |
| 适用限制 | 不适合孕妇、青少年、自身免疫疾病患者 |
| 法规差异 | 欧盟、澳洲等地区对褪黑素有严格限制 |

**我们的方案：以灵芝三萜为核心，构建"安神-助眠-深睡"三重体系。**

### 核心成分1：灵芝三萜 — 安神

灵芝三萜是灵芝发挥安神作用的核心成分。我们采用 **超临界CO₂萃取** 工艺：

| 指标 | 常规水提 | 振隆超临界萃取 |
|-----|---------|---------------|
| 总三萜含量 | 1-2% | **≥8%** |
| 灵芝酸A含量 | 痕量 | ≥1.5% |
| 多糖保留 | 高 | 中（可复配） |
| 苦味 | 轻 | 明显（需矫味） |

**作用机制**：灵芝三萜通过调节 GABA 受体活性，产生类似苯二氮卓类药物的镇静效果，但无成瘾性。研究显示灵芝提取物可缩短入睡时间、延长深睡眠时长。

### 核心成分2：酸枣仁提取物 — 助眠

酸枣仁是中医经典安神药材，"酸枣仁汤"已有2000年历史。我们选用 **皂苷标准化提取物**：

| 指标 | 振隆规格 |
|-----|---------|
| 总皂苷含量 | ≥2% |
| 酸枣仁皂苷A | ≥0.5% |
| 黄酮类 | ≥1% |

**作用机制**：酸枣仁皂苷通过5-HT（血清素）通路调节情绪，同时抑制中枢神经兴奋性，与灵芝三萜形成协同。

### 核心成分3：L-茶氨酸 — 深睡

茶氨酸是绿茶中的特征氨基酸，能够促进α脑波产生，帮助进入放松状态：

| 指标 | 说明 |
|-----|------|
| 纯度 | ≥98% |
| 来源 | 发酵法生产 |
| 推荐剂量 | 100-200mg |

**作用机制**：茶氨酸穿越血脑屏障后，促进多巴胺和GABA释放，在不引起嗜睡的前提下帮助放松入睡。

### 矫味系统

灵芝三萜具有明显苦味，需要精心设计矫味系统：

- **罗汉果苷V**：零热量甜味，掩盖苦味
- **蓝莓浓缩汁**：天然果香，提升口感愉悦度
- **薰衣草香精**：建立"睡眠"心理暗示

### 工艺要点

1. **三萜预乳化**：灵芝三萜为脂溶性，需先用少量MCT油乳化再加入糖体系
2. **分步加料**：茶氨酸对热敏感，在糖液降温至70°C以下后加入
3. **成型控制**：淀粉模成型，确保软糖硬度适中
4. **包装要求**：避光密封，推荐铝箔独立包装
