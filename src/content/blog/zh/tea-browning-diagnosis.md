## 变深和变浑要分开记录

同一批茶粉、同一套配料水，某一天开始茶汤颜色变深，浊度读数却没有同步上升。若把它并入冷后浑或"溶解性差"，下一轮排查会绕开真正变动的那条轴，碱度、矿物盐组成与持液时间都不会进入对照设计。颜色与浊度对应两类不同的变化：褐变来自可溶性呈色产物与儿茶素转化 <a href="#tea-browning-ref-1">[1]</a><a href="#tea-browning-ref-2">[2]</a>，浑浊来自颗粒、络合与沉淀 <a href="#tea-browning-ref-5">[5]</a>。排查的第一步，是让每个样品同时留下色度读数与浊度读数，先确认哪一条在动。

## 碱度决定褐变是否发生

2021 年的茶包浸泡试验把水拆成五档硬度的合成水、一份碳酸氢钠溶液和一份只含其余矿物盐的溶液，用来分开碱度与盐的贡献 <a href="#tea-browning-ref-1">[1]</a>。三份偏碱茶液（碳酸氢钠 pH 7.36、极硬水 pH 7.24、氩气保护的极硬水 pH 7.88）都出现褐变，去离子水对照与矿物盐对照（pH 5.68、5.51）没有褐变 <a href="#tea-browning-ref-1">[1]</a>。同一试验中，EGC 与 EGCG 在偏碱茶液里持续下降，EC、ECG 相对稳定 <a href="#tea-browning-ref-1">[1]</a>；1997 年的另一项模型研究给出同样的稳定性排序 <a href="#tea-browning-ref-6">[6]</a>。EGC 与 EGCG 的 B 环带三个羟基，自由基优先在这样的结构上形成，随后聚合出棕色产物 <a href="#tea-browning-ref-1">[1]</a><a href="#tea-browning-ref-2">[2]</a>。硬水中的碳酸氢根让茶液在浸泡后仍停在偏碱区间 <a href="#tea-browning-ref-1">[1]</a>。

## 矿物盐决定褐变有多快

同一份试验里，矿物盐对照单独存在时茶液偏酸且不褐变；体系一旦偏碱，矿物盐就决定褐变的快慢。起初碳酸氢钠茶液的 470 nm 吸光度最高，随时间推进，含硫酸钙、硫酸镁、氯化钾的极硬水样品反超，EGC、EGCG 的衰减速率也更大 <a href="#tea-browning-ref-1">[1]</a>。钙镁另有独立作用路径：2013 年的试验报告，制备用水钙离子高于 40 mg/L 时茶汤更浑，浊度与草酸、奎宁酸、酒石酸含量负相关 <a href="#tea-browning-ref-5">[5]</a>（该试验条件）。水质变化因此要在两条轴上分别读数，硬度或 TDS 任一单值都不足以判断颜色问题的来源。

## 持液时间决定你看到多少

褐变随时间累积。2021 年的研究中，前两小时碳酸氢钠茶液的 470 nm 吸光度最高，随后极硬水样品超过它；在极硬水茶汤里，每小时约有 3 mg EGC 与 2 mg EGCG 损失 <a href="#tea-browning-ref-1">[1]</a>（该体系数值）。成品一侧，2026 年的绿茶饮料贮藏试验在 4 °C、室温、37 °C、55 °C 四个温度按 3 至 56 天取样，颜色差 ΔE 随温度与时间上升、L* 持续下降，总多酚明显下降而咖啡因与游离氨基酸变化不显著 <a href="#tea-browning-ref-3">[3]</a>；同一批饮料保持清亮，没有明显的冷后浑或沉淀 <a href="#tea-browning-ref-3">[3]</a>。变褐可以在不伴随变浑的情况下单独发生，把"待灌装茶液放了多久、在什么温度"写进批记录，持液时间的累积影响才能和原料差异分开。

## 变褐的路径不止一条

颜色变深至少有两类来源。贮藏研究把酚类化合物的氧化降解与有色美拉德产物并列为颜色变化的主要驱动，同时以儿茶素（尤其 EGCG）的明显下降支持酚类氧化参与其中，并提示游离氨基酸在各贮藏条件下无显著变化，说明美拉德未必是该体系褐变的主要来源 <a href="#tea-browning-ref-3">[3]</a>。模型体系研究则显示，无酶条件下 EC 与 EGC 自动氧化生成的、具有扩展共轭体系与羰基的二聚体和寡聚体负责棕色 <a href="#tea-browning-ref-2">[2]</a>；EGCG 的自动氧化与差向异构受温度、pH、氧分压与抗氧化水平影响 <a href="#tea-browning-ref-9">[9]</a>。控制点因此分成两组：一组是温度与时间，另一组是 pH 与氧暴露。

## 三个读数同日读，只看颜色会误判

每个样品在同一天完成三件事：在固定光程与固定测量温度下读 400–500 nm 区间的吸光，这是棕色物质的主要吸收区间 <a href="#tea-browning-ref-1">[1]</a><a href="#tea-browning-ref-2">[2]</a>；用统一方法读浊度；用 HPLC 或外送谱图核对 EGC、EGCG、EC、ECG 与咖啡因 <a href="#tea-browning-ref-1">[1]</a>。判读规则先写在记录表上：色度上行、浊度平稳，优先查最终 pH、配料水碱度与持液时间；浊度上行、色度平稳，优先查钙镁、草酸盐类与冷却条件 <a href="#tea-browning-ref-5">[5]</a>；两条同时上行，先用调酸把 pH 固定，再比较盐组成，一次只改一个变量。

## 原水与茶液分两层记录

水的记录与茶液的记录分开填。原水一栏写钙、镁、总硬度及单位、碱度及计量基准、pH、电导率、采样点与采样时间；茶液一栏写复溶完成、配方调酸后、热处理后的 pH，以及温度、取样时刻、色度与浊度 <a href="#tea-browning-ref-1">[1]</a><a href="#tea-browning-ref-3">[3]</a>。原水 pH 代替不了茶液 pH：同一研究中，合成水的碳酸氢盐从高到低对应 pH 8.3 到 7.2，浸泡后的茶液 pH 落在 7.1 到 6.0，冲泡本身还会因氨基酸与有机酸释放继续拉低 pH <a href="#tea-browning-ref-1">[1]</a>。偏碱与否，以茶液读数为准。

## 持液取样模板（假设示例）

以下时间点与判据是假设示例，只用于演示取样设计，不对应任何真实批次：同一配制批分装后在 0、1、2、4、8 小时取样，样品回到同一测量温度再读数，颜色记 ΔE 或固定波长吸光度，浊度同步记录，另留一份样做儿茶素谱。该研究正是对同一批茶汤在 4 小时内反复进样，才得到 EGC、EGCG 的衰减曲线 <a href="#tea-browning-ref-1">[1]</a>。取样窗口的两端由现场决定：茶液在灌装前放置多久、在制周转多久，就把这两端包含进去；氧暴露、取样温度、是否同一容器一并记录。固定温度与固定波长让"更深的颜色"可以被比较，也让浓度差异不至于被读成褐变。

## 提取与稳定分开验收

"复溶率"与"放置后还剩多少"是两个指标。冲泡用水研究报告高电导水降低儿茶素与咖啡因的提取，高 pH 主要影响儿茶素稳定性 <a href="#tea-browning-ref-7">[7]</a>；2021 年那项水硬度研究还观察到偏碱条件总体提高提取效率，咖啡因与最稳定的 ECG 在碳酸氢钠茶液中得率更高，同时 EGC、EGCG 损失最快 <a href="#tea-browning-ref-1">[1]</a>。只测初始含量会漏掉持液阶段的变化，只测终点含量又会把提取不足误判成降解。与原料方沟通时分别问三件事：同批茶粉的儿茶素与咖啡因基线、复溶程序、以及放置若干小时后的剩余量。

## 水质研究结论不一致，对照按原料 × 水质设计

水质研究给出的方向并不一致。2021 年那项研究在讨论中记录，Zhou 等人曾报告，以碱性自来水与活性炭吸附水制备的绿茶，其 EGCG、ECG 含量相比低离子强度的酸性水（含去离子水）反而更高 <a href="#tea-browning-ref-1">[1]</a>；2009 年那份报告的摘要写的是活性炭吸附水提高酯型儿茶素浓度、去离子水得率最高 <a href="#tea-browning-ref-8">[8]</a>。水组成、茶原料与测定时点都会改变结论，工程上应保留原料与水质的交叉对照。外推同样要设边界：该研究中"茶液 pH 6.3、硬度 42 ppm CaCO3 以上开始出现褐变"来自茶包 70 °C 浸泡 3 分钟的体系 <a href="#tea-browning-ref-1">[1]</a>，pH 8 以上几分钟内几乎完全降解的观察来自另一份模型溶液 <a href="#tea-browning-ref-6">[6]</a>，pH 4 附近更稳的结论出自浓缩液体系的摘要 <a href="#tea-browning-ref-4">[4]</a>。这些数字用于设计对照，成品饮料的限值仍需在实际配方与实际用水上取得。

## 下一步：把三样记录补齐再做对照

收到"颜色变深"的反馈时，先补齐三样：同批水的完整分析，碱度与计量基准单列；同批茶粉的载体与茶固形物说明；同一温度下刚配好时与放置若干小时后的色度、浊度、儿茶素三轴记录。三样齐全后，问题通常收敛为四个方向：换水或调酸、压缩持液时间、改复溶路线、换粉，此时再进入饮料应用开发讨论并附上对照记录。茶粉复溶、碱度与矿物盐、持液时间这三条因素的组合缺少直接试验文献，先按待验证的工程方案执行并保留记录。冷后浑与沉淀见<a href="/zh/resources/blog/tea-haze-diagnosis">《茶饮冷藏后变浑》</a>，原料形态与规格见<a href="/zh/plant-extracts/ingredients/green-tea">绿茶原料页</a>，即饮饮料采购另见<a href="/zh/resources/blog/green-tea-energy-beverage-2026">《采购检查表》</a>。
