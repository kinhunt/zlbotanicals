同一产线来了两张报障单：一张是杯口一圈一碰就碎的膜，杯内液体照常清亮；另一张是瓶底一层沉淀，杯口干干净净。两张单子最后并成同一个"溶解度问题"，处置也就落到换粉、加大酸量、延长过滤上，而每一条都没对上症。膜长在气–液表面，沉淀长在体相里，两者的化学路径不同，所以第一步是归属判断：眼前这个现象属于哪一类，水能不能解释它。

这个分类上一篇已经给出：《<a href="/zh/resources/blog/tea-haze-diagnosis">茶饮冷藏后变浑：如何区分水质、复溶与低温聚集问题</a>》把冷后浑（cold haze）、粉团、表面膜分成三类，并给出水质 × 复溶 × 储存的八条件筛查。本文接着表面膜这一支往下走——用一个工作日把杯口的膜判到水侧，看清该记哪几个水值，确认归属之后先改什么。

有两处方向相反的细节值得带进实验室。咖啡因在两边的角色对不上：脱咖啡因茶的成膜量与普通红茶相近 <a href="#tea-scum-ref-s06">[S06]</a>，而体相里是茶黄素先长出直径约 3 nm 的簇、咖啡因再往缝隙里填 <a href="#tea-scum-ref-s04">[S04]</a>；透析后的绿茶汤单独加 EGCG 或单独加咖啡因都保持清亮，两者同加才出现可见浑浊 <a href="#tea-scum-ref-s02">[S02]</a>。金属离子也一样：钙在两边都推动现象，但搭档不同——液面上是碳酸氢根，液相里是草酸与多酚。

## 成膜要水里同时有什么

三个条件缺一不可：钙（或镁）、碳酸氢根、足够高的 pH。用纯 Milli-Q 水泡茶不长膜，成膜最强的一档是含 200 mg CaCO₃/L 的硬水 <a href="#tea-scum-ref-s01">[S01]</a>。同一篇把膜描述为承载碳酸盐小岛的高分子有机质，这也是"干膜滴酸"能当现场判据的原因。蒸馏水加标的一组实验进一步确认这个配对：钙与碳酸氢根同时在场才成膜；钙与硫酸根搭配（即永久硬度）则完全不长膜 <a href="#tea-scum-ref-s06">[S06]</a><a href="#tea-scum-ref-s07">[S07]</a>（该系列 1994–1996，摘要级证据）。

这个配对给出了碱度单独成列的具体理由：总硬度告诉你水里有多少钙和镁。碱度是总的酸中和容量，不是碳酸氢根的直接测定，也不等同于临时硬度。对于组成和 pH 已知、以碳酸氢根为主的水，可据此评估碳酸氢根的贡献；碳酸根、氢氧根及其他碱也可能贡献碱度。总硬度的定义与"碳酸盐硬度／非碳酸盐硬度"的划分见 Standard Methods 2340 <a href="#tea-scum-ref-s25">[S25]</a>；Standard Methods 2320 把碱度定义为酸中和容量，其值随所选终点变化 <a href="#tea-scum-ref-s26">[S26]</a>；做 EDTA 滴定的实验室，在 pH 10.0 ± 0.1、铬黑 T 或钙镁指示剂、0.01 M EDTA 条件下的操作步骤见 NC DEQ 的方法认证清单 <a href="#tea-scum-ref-s28">[S28]</a>。中方口径里，GB/T 5750.4-2023 为感官性状和物理指标、GB/T 5750.5-2023 为无机非金属指标 <a href="#tea-scum-ref-s29">[S29]</a>；全国标准信息公共服务平台（国家标准全文公开系统）目前只给出标准记录，引用条款号之前先确认你要的指标落在哪一部分。

**pH 决定成膜速度。** 加标系列所用的 80 °C 体系里，硬水 pH 由 8.2 降到 6.83，液面碳酸钙沉积从 5.3 mg 降到 0.85 mg <a href="#tea-scum-ref-s07">[S07]</a>（索引级；该体系）。pH 还同时牵动另一件事：偏碱的茶汤变褐，EGC 与 EGCG 持续衰减 <a href="#tea-scum-ref-s13">[S13]</a>。偏碱条件下的衰减并不能证明降 pH 必然损失儿茶素或风味。应先量出自家茶汤实际落在哪个区间，再在实际酸化配方中测定儿茶素与风味变化，而不是照搬其他体系的目标值。

**煮沸只能减少，不能消灭。** 原文的结论句是"煮沸使结膜量减少，但没有消除" <a href="#tea-scum-ref-s06">[S06]</a>。煮沸还会带动 pH，方向却不统一：伦敦自来水煮沸 1 s 后 pH 由 8.0 降到 6.67 <a href="#tea-scum-ref-s06">[S06]</a>，合成水体系则因二氧化碳逸出升高 0.5–1.0 个单位 <a href="#tea-scum-ref-s13">[S13]</a>。净效应取决于碳酸氢盐负荷和气体逸出条件，自家水煮沸前后的 pH 要自己测一对值来定。

**器型与保温和成分一样重要。** 成膜速率取决于暴露表面积，与茶汤体积无关：容器口径由 10.28 cm 收到 9.0 cm，成膜速率下降 19%，与面积减少 23% 大体相当，而 60 min 后的膜量照旧 <a href="#tea-scum-ref-s06">[S06]</a>。该系列给出的活化能 34 kJ·mol⁻¹，解释了保温壶中累积一小时的膜为什么比敞口快凉的杯子里多 <a href="#tea-scum-ref-s06">[S06]</a>（摘要／索引级）。做 A/B 对照时容器与装液量必须一致，否则暴露面积会悄悄决定结果。

| 1. 平行泡制 | 同批茶、同投料量、同温度时间；容器与装液量一致。三组：去离子水／现用水／现用水＋螯合剂 | 只有现用水一组长膜 | 问题在水侧 | 回到矩阵表，先处理碱度与 pH，再考虑粉侧 |

步骤 1 另有两个出口：三组全长，说明水不是区分项，转查几何、保温与方法的检出限；三组都不长，说明现象低于该方法的检出限或并非离子驱动。每一步都有各自的文献支撑，先后次序属于工程建议。过滤后取样蒸干以区分溶解性与不溶性固形物，按 Standard Methods 2540 执行 <a href="#tea-scum-ref-s27">[S27]</a>，写进规格前核对本实验室所持版本的子节编号。

## 先改什么，每一档的代价

1. **先动水。** 考虑换水源、配水或软化时，可先从水质对照入手：去离子那一组根本不长膜 <a href="#tea-scum-ref-s01">[S01]</a>。软化去除钙镁；碱度是否随之下降取决于工艺——沉淀软化会去掉碳酸盐硬度，离子交换则基本保留——所以任何处理后都要重测碱度，处理前的硬度值不能代表处理后的新水。
2. **螯合剂分三档选。** 柠檬酸一次走两条路径——降 pH 与络合钙——并明显削弱膜强度 <a href="#tea-scum-ref-s01">[S01]</a><a href="#tea-scum-ref-s07">[S07]</a>。第二档是聚磷酸盐：一项红茶茶汤研究报告它络合钙（不络合铁）、抑制硬水泡茶时的单宁–钙白浊，同时汤色变深、浸出物增加，该体系下 0.15% 及以上风味受损、0.1% 可接受 <a href="#tea-scum-ref-s21">[S21]</a>——这是 1962 年聚磷酸盐大类的单一研究，剂量只代表该体系，具体品种以自家食品级规格复核。第三档走粉侧的酶法：单宁酶在 0.5 mg/mL、120 min、35 °C 的自身体系里降低酯型儿茶素，使绿茶浓缩液沉淀减少 74.63% <a href="#tea-scum-ref-s22">[S22]</a>。EDTA 是最灵敏的实验室判别手段——停止结膜增长 <a href="#tea-scum-ref-s06">[S06]</a>、挽回可逆沉淀部分 <a href="#tea-scum-ref-s14">[S14]</a>——但要进入生产配方，须先按目的地市场法规逐条核对（美国 21 CFR、中国 GB 2760、欧盟 EC 1333/2008 附件）。
3. **加热与保温。** 煮沸降低膜负荷、但无法除根；此后保温温度与暴露面积决定累积量。自家水煮沸前后的 pH 自己测一对值，据此定保温窗口。
4. **过滤与离心放在工艺选项最后。** 上面的研究报告了体相浑浊的推迟——离心后 21 天、超滤后一周。溶解性前体与保温条件不变时，这些证据未证明普通澄清能防止后续成膜。这不代表所有过滤或膜处理：改变可用钙、碳酸氢根或有机前体的处理可能改变后续成膜。应复测处理后的茶汤，不能从体相清亮推定不会成膜。
5. **最后才动粉。** 咖啡因不是成膜的必需成分 <a href="#tea-scum-ref-s06">[S06]</a>，却是冷后浑的结构性参与者 <a href="#tea-scum-ref-s04">[S04]</a>。水侧几组都干净之后再进粉侧——那时要顺着冷后浑的机制查，而非结膜的机制。

| 膜的结果 | 各时间点的覆盖度或膜量，各组用同一套判读方式 |
| 体相的结果 | 复温前后的浊度与外观、沉淀高度或质量 |
| 化学判别 | 干膜酸试；有条件时加做刮取物的显微观察 |
| 结论 | 归属界面还是体相、下一个要改的变量、复核日期 |

</div>

询价索取样品时把"水的输入"一栏一并附上，模糊的"我们水好像有问题"就变成了可比对的记录。供应侧可按项目提供不同茶型与固形物规格，并同步开展水质与工艺评估；上表的试验在您自己的产线上跑，产生的数据属于您的体系。

## 这些数字的边界

文中每个阈值都属于产生它的体系：Ca²⁺ 高于 40 mg/L 来自 1% 绿茶汤 <a href="#tea-scum-ref-s12">[S12]</a>，成膜最强的 200 mg CaCO₃/L 来自人工配水加一种茶 <a href="#tea-scum-ref-s01">[S01]</a>。植奶目前只有体相沉积的研究 <a href="#tea-scum-ref-s23">[S23]</a>，杯口结膜尚无直接工作；铝与铁的证据说的是冷后浑颗粒 <a href="#tea-scum-ref-s24">[S24]</a>。聚磷酸盐一档建立在 1962 年一项大类研究上 <a href="#tea-scum-ref-s21">[S21]</a>。同一次排查里涉及颜色变化的部分，见《<a href="/zh/resources/blog/tea-browning-diagnosis">茶汤变深但不变浑：先查碱度，再看矿物盐与持液时间</a>》。
